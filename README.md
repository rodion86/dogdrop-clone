# DOGDROP — демо открытия кейсов CS2

Демонстрационный сайт в стиле DogDrop: открытие кейсов CS2, инвентарь, апгрейдер скинов,
пополнение виртуального баланса, ежедневный бонус. Полностью статический — без бэкенда и без
настоящих платежей.

**18+ · Демо · Виртуальные деньги и предметы · Не является азартной игрой**

## Что внутри

- **100 кейсов** с реальными названиями и ценами, обложки — из CDN DogDrop.
- **2 142 уникальных скина** (3 553 позиции по кейсам) с реальными картинками, редкостью,
  качеством, оружием и русскими названиями.
- **Открытие кейса**: рулетка с прокруткой, выпавший предмет можно оставить или продать.
- **Инвентарь**: список предметов, сумма стоимости, продажа за 90% цены.
- **Апгрейдер**: до 4 предметов + добор с баланса, круговое колесо шанса, множители `x2/x5/x10`
  и быстрые проценты `30/50/75`, каталог цели с поиском и фильтрами, быстрый режим.
- **Баланс**: демо-пополнение, промокод, ежедневный бонус, «копание» — всё виртуальное.
- Состояние хранится в `localStorage` (ключ `dogdrop_demo_v1`).

## Структура

```
index.html          — вся вёрстка, стили и логика (один файл)
assets/cases/       — 100 обложек кейсов (webp)
assets/skins/       — 1 671 картинка скинов (webp)
assets/skins.js     — каталог скинов (window.DOG_SKINS)
assets/*.svg|webp   — логотип, логотип колеса, плейсхолдер цели
```

## Запуск локально

Любой статический сервер из этой папки:

```bash
python -m http.server 8777
```

и открыть <http://127.0.0.1:8777/>.

Можно открыть и напрямую файлом `index.html` — внешних запросов нет, кроме шрифта Google Fonts
(без него сайт работает на системном шрифте).

## Публикация

Сайт готов к GitHub Pages: ветка `main`, корень репозитория. Всё уже настроено (`.nojekyll`),
достаточно включить Pages в настройках репозитория.

## Сброс демо

Открыть консоль браузера и выполнить:

```js
localStorage.removeItem('dogdrop_demo_v1');
location.reload();
```

## Дисклеймер

Проект сделан как учебное демо интерфейса. Он не связан с DogDrop и Steam, не принимает реальные
платежи, не выдаёт реальные предметы и не является азартной игрой. Все торговые марки принадлежат
их владельцам. 18+.
